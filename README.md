# Rutas para el Alma — instaladores

Aquí se publican los instaladores y las actualizaciones automáticas de la app **Rutas para el Alma**.

Descarga la última versión en [Releases](https://github.com/AlexisPalacioDev/rutas-para-el-alma-releases/releases/latest):

- Windows: `RutasParaElAlma-Setup-<versión>.exe`
- Linux: `rutas-para-el-alma_<versión>_amd64.deb` o `RutasParaElAlma-<versión>-x86_64.AppImage`

Una vez instalada, la app se actualiza sola.
